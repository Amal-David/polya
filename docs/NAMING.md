# Name

The project is **Polya**. The GitHub repository is `Amal-David/polya`, the public
Python namespace and CLI are `polya`, and the source distribution name is
`polya-puzzles`. Source installation is supported; no PyPI publication is claimed.

Existing `puzzleops` imports and commands are compatibility aliases. The operation
IDs and MCP tools `puzzle.find` / `puzzle.run` remain unchanged.

The name reflects the project's interest in reusable problem-solving methods.
It does not imply an affiliation, endorsement, or legal clearance of the name.
