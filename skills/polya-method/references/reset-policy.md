# Fresh-context controller contract

Archive original artifacts and checker receipts before a reset. `Archive.record_verified` records a controller attestation, not automatic verification: only an independent checker may approve it. Content-addressed files are created exclusively and never updated through the API; read-only mode and SHA-256 identify accidental edits. This prototype is NOT adversary-resistant immutable storage, and same-user filesystem access can alter it. For actual deployment, put the archive and duplicate gate in a controller account/service inaccessible to the proposer. No such live integration is installed here.

Canonical experiment identity includes method, exact inputs, budget and version. Preserve those identities across fresh packets, including unsuccessful attempts. Report a duplicate to the proposer without re-executing it; different budgets are intentionally distinct attempts. Semantically equivalent but differently encoded proposals are not detected by an exact hash. A reset is a new model invocation without the previous hypothesis narrative, not deletion of the controller record. Selected verified evidence retains receipt/checker provenance. Account for all previous spending and reset prompt tokens in the same run budget. Stop when the task completes, budgets expire, or authority/evidence is missing.

The helper accepts partial budget dictionaries for narrow unit checks. A real controller must preserve every cumulative counter (input/output tokens, tool calls, wall time, resets), original constraints, and scope; omitted counters never mean renewed or unlimited budget.
