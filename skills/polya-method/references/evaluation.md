# Equal-budget experiment protocol

This package builds contexts and scores supplied submissions. It does not call a model, enforce provider billing, or supply a sandbox. A trusted external runner must meter cumulative input/output tokens, tool calls, elapsed seconds and resets; terminate before caps; and preserve raw provider/tool receipts. Self-reported usage is not sufficient for efficacy claims.

1. Pre-register model version, prompts, frozen skill/library hashes, seed schedule, task IDs, identical Budget, stopping criteria and metrics. CLI skill fingerprints cover SKILL.md and every packaged reference; the runner must additionally hash each actual assembled model context. Generate one manifest per baseline/skill/skill_retrieval with make_manifests; call check_equal_budget. Count the skill, retrieval examples and reset prompts against each arm's total input-token budget. Retrieval consumes time and tool calls. No saved-budget giveaways to the intervention arms.
2. An independent author creates held-out tasks after library freeze. Cluster by mechanism and source before splitting, keep near-duplicates together, and audit source overlap. Toy adaptations in this library are development examples only. Hidden files must be in evaluator-only storage inaccessible to the actual proposer; a directory name alone is not isolation. Public task object is exactly {id, problem}; private gold is exactly {id, expected_answer}. Reserve an untouched final set if tuning occurs.
3. Randomize/counterbalance arm order for each task and repeat paired seeds. All arms use the same allowed tool inventory and independent contexts. Hash context and runner receipts; do not substitute a scripted solver for a model arm. build_context rejects extra public-task fields, but runner access controls must prevent leakage.
4. A submission has exactly answer, method, falsifiable_test, validation, uncertainty. The latter four are nonempty strings. Score answer as exact canonical JSON against the pre-registered gold, so answer representation must be stated in the task. Budget overruns and malformed responses count as failures; report their rates separately. Golds never enter context.
5. Blind reviewers to arm and grade justified method choice, a genuinely falsifiable prediction, independent validation and calibrated uncertainty using a frozen rubric (0 absent/wrong, 1 partial, 2 satisfied). Audit disagreements. Automated exact-answer scoring does not establish these qualities. Report paired accuracy differences and uncertainty intervals, calls/tokens/time distributions, invalid/overbudget rates and per-family outcomes. Small smoke tests support only local observations. No held-out model evaluation or learning gain is claimed by package unit tests.
